🎬 Movie Mania – AI Movie Recommendation System

Movie Mania is an AI-powered movie recommendation application that delivers personalized movie suggestions based on the user's selected genre and preferences. Built using Streamlit, LangChain, and Groq LLM, the application demonstrates how Large Language Models can be integrated into interactive web applications.

✨ Features
🎭 Genre-based movie recommendations
🤖 AI-powered suggestions using Groq LLM
🔗 LangChain integration for prompt management
⚡ Fast and interactive Streamlit interface
🎬 Provides movie titles with brief descriptions
💻 Clean and beginner-friendly project structure
🛠️ Tech Stack
Python
Streamlit
LangChain
Groq API
Prompt Engineering
🚀 How It Works
Select your preferred movie genre.
The application sends a structured prompt to the Groq LLM using LangChain.
The AI generates high-quality movie recommendations.
Results are displayed instantly through the Streamlit interface.
